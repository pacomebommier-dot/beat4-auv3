## Implementation rulings
Fresh dedicated clone/branch used for isolation (no existing working copy to disturb).
AUM Moving=false is treated as held for new recalls; no invented STOP/PAUSE identity. Transition to hold cancels pending requests and ramp, preserving current PC/observed BPM.
AUM current measure downbeat is used for absent-queue scheduling. Explicit queue phase begins at local activation; a STOP-selected project anchors on first observed PLAY. This is an app scheduling convention, not confirmation of Circuit phase. External queued messages stay uncertain until an immediate message establishes activation.
Legacy raw 64..127 memories retained in v1 archive, never silently merged into 0..63. New v2 takes canonical lower memories, conflicts reported.
